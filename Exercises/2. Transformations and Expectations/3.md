# Problem
Suppose $X$ has the geometric pmf $f_X(x) = \frac{1}{3} \left(\frac{2}{3}\right)^x, \ x = 0, 1, 2, \dots$. Determine the probability distribution of $Y = X/(X + 1)$. Note that here both $X$ and $Y$ are discrete random variables. To specify the probability distribution of $Y$, specify its pmf.

# Solution
For discrete transformation we don't have to do chain rule transformations like Theorem 2.1.5, we only have to map.

Let $g(x) = \frac{x}{x+1}$ then

$$
f_Y(g(x)) := f_X(x)
$$
for all $x \in \mathbb{Z}_{\geq 0}$, so for example
$$
\begin{aligned}
f_Y(0) = \frac{2}{3},&& f_Y\left(\frac{1}{2}\right) && f_Y\left(\frac{2}{3}\right) = \frac{4}{27}.
\end{aligned}
$$
