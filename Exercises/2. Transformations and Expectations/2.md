# Problem
In each of the following, find the pdf of $Y$.

(a) $Y = X^2$ and $f_X(x) = 1, \ 0 < x < 1$

(b) $Y = -\log X$ and $X$ has pdf

$$
f_X(x) = \frac{(n+m+1)!}{n! m!} x^n (1 - x)^m, \ 0 < x < 1, \ m, n \ \text{positive integers}
$$

(c) $Y = e^X$ and $X$ has pdf

$$
f_X(x) = \frac{1}{\sigma^2} x e^{-(x/\sigma)^2/2}, \ 0 < x < \infty, \ \sigma^2 \ \text{a positive constant}
$$

# Solution
For each of those we can apply Theorem 2.1.5

## (a)
$g(x) = x^2 \implies g^{-1}(y) = y^{1/2} \implies \frac{d}{dy} g^{-1}(y) = \frac{1}{2}y^{-1/2}$.

As such
$$
f_Y(y) = \underbrace{f_X(y^{1/2})}_{= 1} \frac{1}{2} y^{- 1/2} = \frac{1}{2} y^{-1/2}.
$$

## (b)
$g(x) = -\log(x) \implies g^{-1}(y) = \exp(-y) \implies \left|\frac{d}{dy} g^{-1}(y)\right| = |- \exp(-y)| = \exp(-y)$. As such
$$
\begin{aligned}
f_Y(y) &= f_X(\exp(-y)) (-\exp(-y)) \\
&= \frac{(n+m+1)!}{n! m!} (\exp(-y))^n (1 - \exp(-y))^m \exp(-y) \\
&= \frac{(n+m+1)!}{n! m!} (\exp(-y))^{n + 1} (1 - \exp(-y))^m \\
\end{aligned}
$$

## (c)
$g(x) = \exp(x) \implies g^{-1}(y) = \log(y) \implies \left|\frac{d}{dy} g^{-1}(y)\right| = 1/y$
$$
\begin{aligned}
f_Y(y) &= f_X(\log(y)) \frac{1}{y} \\
&= \frac{1}{\sigma^2} (\log(y))\exp\left(-\frac{\log(y)^2}{2\sigma^2}\right) \frac{1}{y}
\end{aligned}
$$
